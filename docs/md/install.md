# Installation

The latest version of MODX CLI can be installed using our installer script. 

```bash
sh -c "$(curl https://modx.co/scripts/install.sh)"
```

Alternatively, you can download the latest release from our [GitHub repository](https://github.com/modxcms/cloud-modxcli/releases) 
and add the file to your system's PATH.
