# What is MODX CLI?

MODX CLI is a command-line interface tool for MODX CMS. It provides a set of commands to manage and interact with MODX
installations, making it easier to automate tasks and streamline workflows. 

MODX CLI has been primarily designed to enhance workflows within MODX Cloud, but it can be used with other linux-based 
hosting platforms or local development environments.
